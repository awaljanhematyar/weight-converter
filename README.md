# Pounds to Kilograms Converter

JavaScript pounds-to-kilograms converter with input validation, exact conversion factor and accessible result feedback.

Part of my JavaScript practice work. Explore my complete projects on [GitHub](https://github.com/awaljanhematyar) or my [developer portfolio](https://hematyar-professional-portfolio.vercel.app/).

## Features

- Convert pounds to kilograms with the factor 0.45359237.
- Show results to two decimal places.
- Clear stale results for empty or invalid input.
- Keep valid input/results visible rather than clearing them on a timer.

## Run locally

```sh
git clone https://github.com/awaljanhematyar/weight-converter.git
cd weight-converter
```

Serve the folder using VS Code Live Server and open `index.html`. There is no npm installation or build step. Use a modern browser.
